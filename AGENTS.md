# Правила тестирования

Для нового или изменённого поведения пишем только полноценные сквозные тесты через пользовательский вход и реальные внутренние компоненты. Не добавляем точечные тесты функций, хелперов и деталей реализации. Подменять можно только внешние границы, которые нельзя запустить в тесте.
